### 1.2 核心组件说明

| 组件 | 职责 | 技术选型 |
|------|------|----------|
| **Test Engine** | 测试执行引擎，管理测试生命周期 | JUnit 5 |
| **Container Manager** | 容器生命周期管理 | Testcontainers |
| **Kafka Container** | Kafka Broker 容器 | confluentinc/cp-kafka |
| **Database Container** | 数据库容器 | MySQL/PostgreSQL |
| **Service Container** | 微服务容器 | 自定义 Docker 镜像 |
| **Network Manager** | 容器网络管理 | Docker Network |

### 5.2 数据隔离策略

| 策略 | 适用场景 | 优点 | 缺点 |
|------|----------|------|------|
| **事务回滚** | 数据库测试 | 快速、无残留 | 无法测试提交后逻辑 |
| **数据清理脚本** | 复杂数据关系 | 灵活可控 | 需要维护清理脚本 |
| **唯一前缀/后缀** | Topic/表名 | 并行安全 | 需要清理机制 |
| **独立容器** | 完全隔离 | 最干净 | 启动慢、资源占用高 |
