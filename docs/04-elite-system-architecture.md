## 5. 关键技术组件

### 5.1 组件清单

| 组件 | 类型 | 职责 |
|------|------|------|
| **Elite Web Frontend** | UI | 用户交互界面，WebSocket 状态订阅 |
| **Elite Backend Service** | 核心服务 | 交易处理、数据落地、消息发布 |
| **OTC Subscription Service** | 生产者 | 轮询数据库，发布消息到 Kafka |
| **Downstream Consumer** | 消费者 | 消费核心数据事件，业务处理 |
| **Payment Consumer** | 消费者 | 消费 Payment 事件，调用 Payment API |
| **Payment API Service** | 外部服务 | Payment 生成服务 |
| **WebSocket Server** | 推送服务 | 实时状态推送 |
| **Apache Kafka** | 消息中间件 | 异步消息传递 |
| **Database** | 数据存储 | 业务数据持久化 |

### 5.2 Kafka Topics

| Topic 名称 | 用途 | 生产者 | 消费者 |
|------------|------|--------|--------|
| `stp_generate_ticket_events` | 核心交易数据分发 | OTC Subscription Service | Downstream Consumer |
| `post_trade_action` | Payment 事件 | Elite Backend | Payment Consumer |

### 5.3 数据库表

| 表名 | 架构模式 | 用途 |
|------|----------|------|
| `stp_generate_ticket` | 架构1 | 待分发的交易数据 |

| `stp_ticket` | 架构1 | 下游处理结果 |
